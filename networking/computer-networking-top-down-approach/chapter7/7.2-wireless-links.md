# 7.2 Wireless Links and Network Characteristics

## Wireless Link Impairments

- **Path loss (decreasing signal strength)** — electromagnetic radiation attenuates through matter and disperses in free space; signal strength drops with distance
- **Interference from other sources** — devices in same frequency band interfere (e.g., 2.4 GHz phones + 802.11b); background EM noise from motors, microwaves, etc.
  - Reason many newer 802.11 standards moved to 5 GHz band
- **Multipath propagation** — portions of EM wave reflect off objects/ground, arrive via paths of different lengths → blurred received signal; changes over time as objects move

## SNR and BER

- **SNR (Signal-to-Noise Ratio)** — relative strength of received signal vs. background noise; measured in dB
  - `SNR (dB) = 20 × log10(amplitude_signal / amplitude_noise)`
  - Higher SNR → easier to extract signal from noise
- **BER (Bit Error Rate)** — probability a transmitted bit is received in error

### Key SNR/BER Relationships (from Fig 7.3)

1. **Higher SNR → lower BER** (for fixed modulation)
   - Sender can increase SNR by increasing TX power → lower BER
   - Tradeoff: more energy drain (battery), more interference with other senders
2. **Higher-rate modulation → higher BER** (for fixed SNR)
   - Example at SNR=10 dB: BPSK @ 1 Mbps → BER < 10⁻⁷; QAM16 @ 4 Mbps → BER = 10⁻¹
   - Example at SNR=20 dB: QAM16 @ 4 Mbps → BER = 10⁻⁷ (acceptable)
3. **Adaptive modulation** — dynamically select modulation technique based on channel conditions
   - Used in 802.11 WiFi and 4G/5G cellular
   - Goal: maximize transmission rate subject to acceptable BER

## Hidden Terminal Problem

- Physical obstructions or fading can prevent two stations (A and C) from hearing each other, even while both are transmitting to a third station (B) where they collide
- **Scenario (a)**: mountain/building blocks A from hearing C
- **Scenario (b)**: fading — A and C too far apart to detect each other's signal, yet strong enough to interfere at B
- Makes multiple access far more complex than wired networks

## 7.2.1 CDMA (Code Division Multiple Access)

### Concept
- Channel partitioning protocol — partitions the **codespace** (vs. time or frequency)
- Each sender gets a unique M-bit code; each bit of data is multiplied by the full code (spread)
- **Chipping rate** — rate at which the code changes; much faster than data bit rate

### Encoding (single sender)
Each data bit `d_i` (represented as +1 or -1) is transmitted as M mini-slots:

```
Z_i,m = d_i × c_m      (Eq. 7.1)
```
where `c_m` is the m-th chip of the sender's M-chip code.

### Decoding (single sender)
```
d_i = (1/M) × Σ(m=1 to M) Z_i,m × c_m      (Eq. 7.2)
```

### Multiple Senders
- Received signal is the **additive sum** of all N senders' transmitted bits:
  ```
  Z*_i,m = Σ(s=1 to N) Z^s_i,m      (aggregate signal)
  ```
- Receiver recovers sender s's data using sender s's code:
  ```
  d_i = (1/M) × Σ(m=1 to M) Z*_i,m × c_m      (Eq. 7.3)
  ```
- Works only if codes are **carefully chosen** (orthogonal) and received signal strengths are equal (hard in practice)

### Example
- Sender 1 code: `(1, 1, 1, -1, 1, -1, -1, -1)` (M=8)
- Sender 2 code: `(1, -1, 1, 1, 1, -1, 1, 1)` (M=8)
- Receiver can extract each sender's bits from the aggregate signal using the respective code

# 7.1 Introduction

## Elements of a Wireless Network

- **Wireless hosts** — smartphones, tablets, laptops, IoT devices; may or may not be mobile
- **Wireless links** — connect hosts to base stations or other hosts; vary by transmission rate and coverage range
- **Base station** — sends/receives data to/from wireless hosts in its coverage area; no direct wired-network counterpart
  - Cell towers (cellular), access points (802.11)
  - Hosts associated with a base station operate in **infrastructure mode**
- **Network infrastructure** — the larger wired network the base station connects into

### Handoff / Handover
When a mobile host moves from range of one base station to another, it changes its **point of attachment** — this is **handoff (handover)**. Raises questions: how to locate mobile host, how to route to it, how to maintain TCP connections through the move.

## Wireless Link Characteristics (Fig 7.2 — rough ranges)

| Technology | Range | Data Rate |
|---|---|---|
| Bluetooth | 10–30 m (indoor) | up to 3 Mbps |
| 802.11 (WiFi) | 30–70 m (indoor) | up to 14 Gbps (WiFi 6) |
| 4G LTE | 4–15 km | 20+ Mbps typical |

## Taxonomy of Wireless Networks

| Type | Description | Examples |
|---|---|---|
| Single-hop, infrastructure-based | Base station connected to wired net; all comms via single wireless hop | 802.11 (WiFi), 4G LTE |
| Single-hop, infrastructure-less | No base station; one node may coordinate | Bluetooth (piconet) |
| Multi-hop, infrastructure-based | Base station present; some nodes relay through other wireless nodes | Wireless mesh, some sensor networks |
| Multi-hop, infrastructure-less | No base station; nodes relay among themselves; nodes may be mobile | MANETs, VANETs |

- **MANET** (mobile ad hoc network) — nodes mobile, connectivity changes
- **VANET** (vehicular ad hoc network) — MANET where nodes are vehicles
- Chapter focus: **single-hop, infrastructure-based** networks

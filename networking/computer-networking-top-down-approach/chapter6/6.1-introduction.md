# 6.1 Introduction to the Link Layer

## Terminology

- **Node**: any device running a link-layer protocol — hosts, routers, switches, WiFi APs
- **Link**: communication channel connecting adjacent nodes along a path
- **Frame**: link-layer PDU that encapsulates a network-layer datagram
- Datagram traverses a series of links; at each hop, the node encapsulates it in a new frame

### Transportation Analogy

| Networking | Transportation |
|------------|---------------|
| Tourist (passenger) | Datagram |
| Transportation segment (limo/plane/train) | Link |
| Transportation mode | Link-layer protocol |
| Travel agent | Routing protocol |

## 6.1.1 Services Provided by the Link Layer

Services vary by protocol; not all protocols provide all services:

### Framing
- Every link-layer protocol encapsulates datagrams in frames before transmission
- Frame = data field (the datagram) + header fields
- Structure specified by the protocol

### Link Access (MAC)
- **MAC protocol**: rules for transmitting frames onto the link
- Point-to-point link: trivial or nonexistent MAC (single sender/receiver)
- Broadcast link: MAC coordinates multiple senders → **multiple access problem**

### Reliable Delivery
- Guarantees each datagram crosses the link without error (via ACKs + retransmissions)
- Useful on high-error-rate links (e.g., wireless) for local correction
- **Considered overhead on low-BER links** (fiber, coax, twisted-pair copper) — many wired protocols omit it

### Error Detection and Correction
- Transmitting node inserts error-detection bits; receiving node checks them
- More sophisticated than IP/TCP checksums
- Implemented in hardware
- **Error detection**: receiver finds a bit is wrong
- **Error correction**: receiver finds AND corrects the wrong bit

## 6.1.2 Where Is the Link Layer Implemented?

```
Host
┌─────────────────────────────────────────────┐
│  Application                                 │
│  Transport                    ← software     │
│  Network                                     │
│  ─────────────────────────────────────────   │
│  Link (upper)  ← link-layer software (CPU)   │
│  Link (lower)  ← NIC hardware (adapter chip) │
│  Physical      ← NIC hardware                │
└─────────────────────────────────────────────┘
```

### NIC (Network Interface Controller / Network Adapter)
- Implements most link-layer functionality in dedicated hardware
- Examples: Intel 700-series (Ethernet), Atheros AR5006 (802.11 WiFi)
- **Sending side**: takes datagram from host memory, encapsulates in frame, transmits per link-access protocol
- **Receiving side**: receives frame, extracts datagram, performs error detection, passes up to network layer

### Software Component (runs on host CPU)
- Assembles link-layer addressing info
- Activates controller hardware
- Handles controller interrupts on receive
- Handles error conditions, passes datagram up to network layer

> The link layer is the junction where software meets hardware in the protocol stack.

# 1.1 What Is the Internet?

## Two Views of the Internet

### Nuts-and-Bolts Description

- **End systems (hosts):** all connected devices — desktops, smartphones, tablets, IoT (TVs, thermostats, cars, etc.)
  - ~18 billion devices in 2017; projected 28.5 billion by 2022
  - Close to half the world's population are active mobile Internet users (projected 75% by 2025)
- **Communication links:** coaxial cable, copper wire, optical fiber, radio spectrum — each with a transmission rate in bits/sec
- **Packet switches:** forward packets toward destination
  - **Routers** — used in network core
  - **Link-layer switches** — used in access networks
- **Packets:** data segmented + header bytes added; reassembled at destination
- **Route/path:** sequence of links + switches a packet traverses from source to destination
- **ISPs (Internet Service Providers):** end systems access the Internet through ISPs
  - Residential ISPs: cable/telephone companies
  - Corporate, university, WiFi-hotspot, cellular ISPs
  - Each ISP is itself a network of packet switches + communication links
  - Lower-tier ISPs interconnect via national/international upper-tier ISPs
  - Upper-tier ISPs: high-speed routers interconnected with high-speed fiber-optic links
  - Each ISP runs IP protocol; conforms to naming/address conventions

### Key Protocols

- **TCP (Transmission Control Protocol)** — reliable, ordered, flow-controlled delivery
- **IP (Internet Protocol)** — specifies datagram format; how routers/hosts act on those fields
- **TCP/IP** — the Internet's principal protocol suite

### Standards Bodies

| Body | Role |
|------|------|
| **IETF** (Internet Engineering Task Force) | Develops Internet standards |
| **RFCs** (Requests for Comments) | IETF standards documents; ~9000 RFCs exist |
| **IEEE 802** | LAN standards (Ethernet, WiFi) |

### Services Description (Infrastructure View)

- Internet = infrastructure providing services to **distributed applications**
- Distributed applications run on **end systems** (not in packet switches)
- End systems expose a **socket interface** — rules a sending program follows to deliver data to a destination program
- Internet provides **multiple services** (like postal service offers express, ordinary, etc.)

## 1.1.3 What Is a Protocol?

**Definition:**
> A protocol defines the **format** and the **order** of messages exchanged between two or more communicating entities, as well as the **actions taken** on the transmission and/or receipt of a message or other event.

### Protocol Properties
- Two entities must run the **same protocol** to accomplish a task
- Every activity involving two or more remote communicating entities in the Internet is governed by a protocol
- Examples:
  - Hardware-implemented protocols control bit flow on NIC-to-NIC links
  - Congestion-control protocols control packet transmission rates
  - Routing protocols determine packet paths

# 5.1 Introduction — Network Layer: Control Plane

**Source:** Kurose & Ross, *Computer Networking: A Top-Down Approach*, 8th ed., pp. 378–380

---

## Overview

- **Data plane** (Ch. 4): forwarding table / flow table — local, per-router packet forwarding
- **Control plane** (Ch. 5): computes, maintains, and installs those tables — network-wide logic

---

## Two Approaches to Control Plane

### Per-Router Control (Traditional)

```
[Router A] ←──routing msgs──→ [Router B] ←──routing msgs──→ [Router C]
     │                               │                               │
 [fwd table]                    [fwd table]                    [fwd table]
```

- Each router runs its own routing algorithm component
- Routing components communicate directly with each other to compute forwarding tables
- Used by OSPF (§5.3) and BGP (§5.4)
- Internet standard approach for decades

### Logically Centralized Control (SDN)

```
         ┌─────────────────────────┐
         │   Logically Centralized │
         │       Controller        │
         └──────────┬──────────────┘
          ┌─────────┼─────────┐
         CA        CA        CA      ← Control Agents (minimal logic)
          │         │         │
       [Router]  [Router]  [Router]  ← data plane only
```

- Remote controller computes forwarding/flow tables; pushes them to routers
- Each router has a **Control Agent (CA)**: minimal functionality — communicates with controller, follows commands
- CAs do **not** interact with each other; do **not** compute tables independently
- "Logically centralized" = accessed as single service point, but physically implemented on multiple servers (fault tolerance, scalability)

## SDN Adoption Examples

| Deployment | Details |
|---|---|
| Google B4 | SDN controls internal global WAN interconnecting data centers [Jain 2013] |

| Deutsche Telekom Access 4.0 | Production SDN integration |

| 4G/5G cellular | SDN control central to cellular networking (Ch. 8) |

---

## Key Distinction

| Feature | Per-Router | Logically Centralized |
|---|---|---|
| Routing algorithm location | Every router | Controller (external) |
| CAs interact with each other? | Yes (directly) | No |
| CAs compute forwarding tables? | Yes | No (controller does it) |
| Example protocols | OSPF, BGP, RIP | OpenFlow + SDN controller |
